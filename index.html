Configurar teclas
Como usar localmente (desconsiderar se usado no browser)
  1. Deixe este arquivo HTML dentro de uma pasta fácil de achar, por exemplo, na Área de Trabalho.
  2. Abra essa pasta, clique na barra de endereço do Explorador de Arquivos, digite cmd e aperte Enter. Isso abre o Prompt de Comando já nessa pasta.
  3. No Prompt de Comando, digite py -m http.server 8000 e aperte Enter. Deixe essa janela aberta enquanto estiver usando a página.
  4. No navegador, acesse localhost:8000, clique em index.html, cole o link do YouTube e use as teclas configuradas. Para trocar uma tecla, altere a letra em Configurar teclas; cada campo aceita apenas uma letra e não pode repetir outra tecla.
